# Data

本目录用于逐步发布经过核验、适合公开再利用的结构化专利价值研究数据。

## 数据分层

数据可以来自不同研究场景，包括：
- 通用专利价值样本
- 技术 / 产品 / 工艺实施案例
- 许可、交易、诉讼、标准、维持等价值证据
- 中国专利奖专项样本
- 其他可公开复核的历史或现实世界样本

**是否获奖不是通用数据集的正负标签。**

中国专利奖 Gold / Silver / Excellent 数据属于独立研究模块，可以作为：
- 奖项专项研究数据；
- 某些value construct的外部验证信号；
- 模型历史形成证据。

但不能直接等同于：
- 高经济价值 / 低经济价值；
- 高私人资产价值 / 低私人资产价值；
- 通用模型 ground truth。

## 发布原则

公开记录优先保存：
- 专利结构化事实
- Value Construct
- Value Realization Stage
- Evidence / Attribution State
- Observability
- Rights Control相关事实（逐步加入）
- Source Registry ID
- 来源日期
- T0 截断状态
- Confirmed / Strong Evidence / Inference / Unknown
- 研究版本

不直接批量复制受版权、数据库许可或第三方授权限制的全文材料。

企业私有经营数据、客户资料、合同与受限数据库内容不进入 Public Layer。
