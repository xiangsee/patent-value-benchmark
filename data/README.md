# Data

本目录用于逐步发布经过核验、适合公开再利用的结构化基准数据。

当前阶段暂不批量发布未经清洗的 Gold / Silver / Excellent 数据。

## 发布原则

公开记录优先保存：
- 专利与奖项的结构化事实
- 官方来源 URL / Source Registry ID
- 来源日期
- T0 截断状态
- Evidence Level
- Confirmed / Strong Evidence / Inference / Unknown
- 研究版本

不直接批量复制受版权、数据库许可或第三方授权限制的全文材料。

企业私有经营数据、客户资料、合同与受限数据库内容不进入 Public Layer。
