# China Patent Award Research

状态：长期独立专项模块

本模块专门研究中国专利奖，包括金奖、银奖、优秀奖及其历届制度与结果。

它与通用 `Patent Value Benchmark` 相互连接，但不是同一个研究问题。

## 核心问题

1. 历届金奖 / 银奖 / 优秀奖的结构和分布如何变化？
2. 同届、同技术领域、相似主体与申请时间的项目之间，有哪些可观察差异？
3. 评奖规则、政策导向与实际获奖结果之间是什么关系？
4. 获奖专利后来是否形成了可验证的产品、工艺、许可、标准、诉讼或经济价值？
5. 哪些金奖研究变量能够迁移到一般专利价值研究，哪些只能解释奖项本身？

## 研究边界

本模块允许研究：
- award readiness
- award criteria
- Gold / Silver / Excellent differences
- award outcome correlations

但这些结论默认只属于“中国专利奖研究”。

只有经过独立机制论证和非奖项样本验证的变量，才可以进入通用 Patent Value Benchmark。
