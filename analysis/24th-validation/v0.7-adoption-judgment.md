# V0.7 Architecture Adoption Judgment

日期：2026-09-24

## Decision

**Adopt V0.7 as the Xiangsee Patent Value Benchmark research architecture.**

重要限定：

> V0.7 是“专利价值与证据研究架构”，不是 Gold / Silver 预测模型，也不输出获奖概率。

## Why adopt

V0.7由第25届10组配对提出，并在未用于架构设计的第24届4组跨届样本上进行外部压力测试。

四组均反复暴露同一种混淆风险：

1. 现实价值很高，但exact-patent attribution不公开；
2. 公开证据非常完整，但奖项等级并不因此被决定；
3. 产品/企业的R4不能自动继承到专利；
4. post-T0 ground truth不能回填T0；
5. “Unknown”经常是observability问题，而不是low-value判断。

V0.7四层架构能够在不增加虚假精确度的情况下表达这些状态。

## Adopted architecture

### Layer 1 — Value State
记录现实中的技术、产品、工程、临床、市场和社会价值状态。

### Layer 2 — Attribution / Evidence State
记录这些价值能够在多大程度上被归因到exact patent，以及证据等级E1–E5。

### Layer 3 — Observability State
- Public
- Disclosed / Regulated
- Internal
- Restricted
- Unknown

### Layer 4 — Value Realization Stage
- R0 Right Exists
- R1 Market / Transfer Intent
- R2 Rights Transaction
- R3 Implemented in Value Carrier
- R4 Scaled Real-world Validation
- R5 Patent-level Attributable Value

## What V0.7 explicitly refuses to do

V0.7不允许：
- 用企业营收替代专利价值；
- 用产品销量自动推导专利贡献；
- 把许可挂牌等同于实施；
- 把实施等同于规模验证；
- 把规模验证等同于专利级归因；
- 把公开搜不到编码成0；
- 使用未来获奖宣传重写历史T0；
- 输出虚假的Gold probability。

## Validation status

- 第25届：10组，用于架构形成
- 第24届：4组，用于外部压力测试
- 结论：**architecture adopted**
- 预测能力：**not claimed / not validated**

## Next validation target

下一阶段不再验证“架构有没有必要”，而验证：
1. V0.7能否稳定编码更多历史届次；
2. 不同研究者对同一证据能否得到较一致的状态判断；
3. R0–R5与E1–E5能否支持企业内部Patent Value Ledger；
4. 哪些字段能够公开成为行业共同标准。
