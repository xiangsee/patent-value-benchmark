# 第24届外部验证：Round 3 — 生物医药强对照

日期：2026-09-24  
T0：**2022-10-31**  
模型：V0.7 Proposal

## P24-BIOLOGIC-001

Gold：
- ZL03816434.5
- 《HIV感染的肽衍生物融合抑制剂》
- 前沿生物

Silver：
- ZL202010537730.0
- 《新型冠状病毒Vero细胞灭活疫苗病毒液及其生产方法》
- 北京生物制品研究所 / 中国生物

这是第24届目前最强的一组压力测试之一，因为两边在T0前都已经不是“研发项目”，而是进入真实医疗与公共卫生体系的技术资产。

## 1. Gold：艾可宁形成了非常完整的公开价值链

2020年上交所审核披露文件明确说明：
- ZL03816434.5 属于艾博韦泰（Albuvirtide）产品技术；
- 艾博韦泰产品技术是艾可宁产品研发所依赖的核心技术；
- 同时文件谨慎指出，产品技术整体大于任一单独专利，历史评估也不是单独对中国专利进行市场价值评估。

因此这是一个非常理想的 E3 案例：

`Exact Patent → Albuvirtide Product Technology → Aikening`

产品本身在2018年已经获批上市。

到2021年：
- 销量 111,834 支；
- 销售收入 4,050.29 万元；
- 覆盖全国28个省的200余家HIV定点治疗医院；
- 覆盖100余家DTP药房。

所以T0前可以稳健判断：
- Value State：成熟；
- E3：Confirmed；
- R4：Confirmed；
- E4 / R5：仍然 Unknown。

即使产品收入已经公开，也不能把4,050.29万元全部归因到ZL03816434.5这一件中国专利。

## 2. Silver：现实公共卫生价值更大，但专利级归因仍是另一件事

Silver专利本身直接权利要求：
- SARS-CoV-2 Vero细胞病毒液生产方法；
- 由该方法得到的病毒液；
- 进一步制成的新冠灭活疫苗。

国家卫健委2021年技术指南明确：
- 北京生物制品研究所生产的灭活疫苗已经附条件批准上市；
- 该类疫苗使用Vero细胞进行病毒培养扩增。

WHO在2021年将北京生物/CNBG的BIBP-CorV列入紧急使用清单。

同年，国药集团披露北京生物与Gavi签署COVAX供应协议，可向COVAX提供最多1.7亿剂北京生物新冠灭活疫苗。

因此T0前，Silver对应技术的现实价值已经非常巨大。

但是研究纪律要求我们仍然区分：

- **产品级事实**：BIBP-CorV已经获批、WHO EUL、全球供应；
- **专利级事实**：ZL202010537730.0覆盖Vero细胞灭活疫苗病毒液生产及疫苗制品；
- **exact patent→product**：结合权利人、技术路线和官方产品描述，属于Strong Evidence；
- **E4 / R5**：仍不能把所有疫苗产能、接种价值或公共卫生贡献归因给这一件生产方法专利。

## 3. 这一组真正检验了什么

如果模型只是“销售额/规模越大越高价值”，Silver反而可能显得比Gold更强。

但这正说明为什么不能把高价值专利研究变成规模排行榜。

V0.7需要同时表达四件事：

1. **Value State**：两边都有真实且巨大的医疗价值；
2. **Attribution / Evidence**：Gold的exact-patent链条公开得更直接；Silver是Strong Evidence；
3. **Observability**：两边都高度可观察，但观察制度不同；
4. **Realization Stage**：两边都至少到R4，R5仍然缺失。

因此本组不支持“为什么Gold胜过Silver”的结论。

它支持的是：

> 当两项专利都高度成功时，Value、Attribution和Observability仍然必须分开，否则模型会把产品规模误当成专利价值。
