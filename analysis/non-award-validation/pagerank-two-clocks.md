# Non-award V0.8 Pressure Test — PageRank / Stanford → Google / US 6,285,999

日期：2026-09-25  
状态：Round 3 experimental — not an adopted model change  
研究线：Track A — Patent Value Benchmark

## 结论先行

这一轮没有完全按原先预期得到“早期R0/R1 option value”的干净样本。

这是一个应该保留的反证。

Stanford 2000年前后的同时期资料已经显示，PageRank很早就进入了高强度真实使用；到2004年公开申报材料时，Google已经是大规模商业系统。

因此：

> **PageRank不是一个干净的“尚未实现价值”的early-stage option sample。**

本轮不强行把它改写成符合假说的故事。

PageRank真正适合检验的是：

# Patent Age的“两只钟”

也就是：

1. **Survival / Revealed-value Clock**  
   随时间增加，持续实施、持续许可、持续商业成功积累了越来越多的“过去价值已经真实发生”的证据。

2. **Remaining-exclusivity Clock**  
   同样随着时间增加，独占许可剩余窗口和专利剩余期限不断缩短，未来可由排他性捕获的价值窗口反而下降。

## 一、为什么选两个T0

为了避免把后来成功倒灌给早期，本轮为同一件专利建立两个独立Ledger：

- **T0-A：2004-08-04**
- **T0-B：2009-02-13**

每个Ledger只使用该T0及以前已经公开的信息。

## 二、T0-A：2004-08-04

Google在S-1/A中公开：

- PageRank是Google网页排名技术的一个组成部分；
- PageRank源自在Stanford的研究；
- Stanford拥有PageRank专利；
- Google持有永久许可；
- 独占期持续到2011；
- 专利当时被披露为将在2017年到期。

同一份材料还显示：

- Google 2003年收入约 **USD 1.466bn**；
- 2004年上半年收入约 **USD 1.352bn**；
- Google已经索引超过40亿网页；
- PageRank与其他ranking/text-matching技术共同构成搜索系统。

因此在V0.7里，这一时间点并不是R0/R1。

更合理的是：

> **R4 — Scaled Real-world Validation**

也就是说：

> PageRank在2004年已经不是“等待商业化的专利”。

但这并不意味着Option/Future Value已经消失。

恰恰相反，2004年的资产状态同时具备：
- 已实现价值；
- 较长的未来商业增长空间；
- 仍有多年独占许可窗口；
- 较长剩余专利寿命。

所以更准确的表达不是：

`realized OR option`

而是：

`realized + option/future horizon`

二者可以并存。

## 三、T0-B：2009-02-13

五年以后，Google的10-K仍然明确写道：

- PageRank仍是网页排名技术的一个组成部分；
- Stanford仍拥有PageRank专利；
- Google持有永久许可；
- 独占期到2011；
- 专利当时仍被披露为将在2017年到期。

而Google 2008年总收入已经达到：

> **USD 21.79555bn**

与2004相比，现实世界的成功证据显著增强。

但是法律控制窗口却发生相反变化：

- 2004：距离独占期结束还有多年；
- 2009：距离2011年独占期结束已经明显更近；
- 之后Google仍可继续使用，但许可将转为non-exclusive。

于是出现一个很重要的结构：

```text
              2004                     2009
Realized      already strong      →    much stronger
Evidence      accumulating        →    much richer
Survival      shorter history     →    longer history

BUT

Exclusive
horizon       relatively long     →    much shorter

Patent
remaining
term          longer              →    shorter
```

## 四、V0.7在这里出现了什么问题

两个时间点进入现有模型后，都会得到：

> **R4 — Scaled Real-world Validation**

而且：
- exact patent → value carrier = confirmed
- real-world validation = confirmed
- scale = confirmed
- patent-level attributable value = unknown

这些判断都没有错。

问题是：

> **R4无法告诉我们，2004年的R4和2009年的R4在资产经济含义上已经不同。**

如果把R-stage误当“价值大小”，就会丢失时间维度。

因此：

# Realization Stage不是Value Level

R4只是状态分类，不是一个跨时间可比较的价值分数。

## 五、“年龄越长价值越高”也是错的

PageRank非常适合解释我们前面发现的年龄悖论。

随着时间推移：

### 正向钟：Survival / Revealed Value

越来越多的事实支持：
- 技术持续实施；
- 许可关系持续；
- 产品持续扩散；
- 商业体系持续增长。

这会增强“这项资产过去确实有价值”的证据。

### 反向钟：Remaining Exclusivity

但与此同时：
- 专利保护期不断消耗；
- 独占许可的剩余时间不断缩短；
- 未来由排他权直接捕获的增量价值窗口变小。

所以：

> **Patent age本身不能是一个单向加分或减分变量。**

必须拆成至少两只钟。

## 六、H2的结果需要拆开

Issue #5中的H2原本写的是：

> The same patent can have high option value early, strong realized value later, and declining rights value near expiry.

PageRank对其中两部分提供了强支持：

### H2a — Value is date- and context-dependent

**Supported by the same-patent two-T0 test.**

同一US6285999，在不同T0的经济含义确实不同。

### H2b — Two Clocks

**Supported.**

revealed-value history与remaining-exclusivity明显朝相反方向变化。

### H2c — Clean early-stage option sample

**Not cleanly tested by PageRank.**

原因不是找不到故事，而是现有同期公开证据显示PageRank很早就已经大规模实施。

因此不能为了预注册假说，把真实样本硬压成R0/R1。

这个子假说需要另找真正的early-stage patent样本。

## 七、这一轮还发现一个重要的估值纪律

Google企业收入从约14.66亿美元增长到217.96亿美元，非常醒目。

但我们仍然不能写：

> “PageRank专利价值增长了15倍。”

原因是Google自己明确说明：

> PageRank只是ranking technology的一个组成部分，Google形成以后还发展了大量其他ranking、text-matching、广告、基础设施和商业技术。

所以两个Ledger都坚持：

- enterprise revenue = context
- patent-level attributable value = Unknown

这再次证明：

> **企业增长可以证明环境中的价值实现，但不能自动成为单专利估值。**

## 八、对V0.8的暂定影响

本轮仍然不改Schema。

但V0.8候选层现在进一步清晰：

```text
VALUE HORIZON
├─ realized_value_history
├─ survival / revealed-value clock
├─ remaining_exclusivity clock
├─ remaining_patent_term
└─ option / future value
```

其中：

- `survival_clock` 与 `remaining_exclusivity_clock` 应明确分离；
- `R0–R5` 不承担价值大小或时间折旧功能；
- 同一专利可以有多个T0 Ledger，而不能只保留一个“最终状态”。

## 九、研究治理上的一个修正

原研究议程写了：

> 选择R0/R1但后来成为重大产品/标准的历史专利。

PageRank不满足这个要求。

因此本轮结论是：

> **PageRank完成Two Clocks测试，但不计入“4个early-stage option retrospectives”的完成数。**

这条不因为样本有名就放宽。
