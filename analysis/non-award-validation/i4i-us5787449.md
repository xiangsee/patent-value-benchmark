# Non-award V0.8 Pressure Test — i4i v. Microsoft / US 5,787,449

日期：2026-09-24  
状态：Round 1 experimental — not an adopted model change  
研究线：Track A — Patent Value Benchmark

## 为什么选它

这是V0.8第一件**完全不依赖奖项标签**选择的样本。

它不是因为获奖、未获奖、进入“高价值专利”统计口径而进入样本，而是因为它能直接测试一个机制问题：

> **当一件专利已经出现 exact-patent → product feature → infringement → monetary award → injunction 的公开证据链时，V0.7还能遗漏什么？**

## T0

T0 = 2010-03-10，Federal Circuit重新判决日。

只使用T0及以前已经公开的信息描述当时状态。当前专利是否已到期等post-T0信息不回填。

## V0.7能够表达的部分

### 1. Exact patent → value carrier

Federal Circuit记录：
- 争议专利为US 5,787,449；
- certain Microsoft Word versions中的custom XML editor构成侵权；
- 陪审团侵权结论被维持。

因此：
- exact patent mapping = confirmed
- E3 = confirmed

### 2. Patent-level monetary evidence

陪审团判给i4i 2亿美元损害赔偿。

该金额直接来自围绕US 5,787,449的侵权案件，因此可以作为：
- E4 patent-level attributable monetary evidence
- R5 evidence

但必须加上限制：

> **这2亿美元不是“这件专利值2亿美元”的一般估值结论。**

Federal Circuit明确指出，由于Microsoft没有在判决前以JMOL方式保留该项挑战，上诉法院不能重新决定陪审团损害赔偿是否有充分证据支持。

因此金额的正确语义是：

> **dispute-specific adjudicated damages evidence**

而不是：

> intrinsic patent price / universal market value。

### 3. Enforcement

Federal Circuit维持永久禁令，仅调整生效日期。

这为“权利是否真的具有排除效果”提供了比引用量、家族规模或维持年限更直接的现实证据。

## V0.7暴露出的缺口

V0.7可以表达：
- R5
- E3 / E4 / E5
- exact patent mapping
- patent-level monetary evidence

但它仍然不能结构化表达：

- claim scope
- validity resilience
- enforceability
- remaining term
- non-infringing alternatives / design-around
- blocking power
- counterfactual dependency

这些信息被迫塞进notes，而不是成为可比较状态。

## 对H1/H4的初步结果

### H1 — Rights Control

**Provisional support, not adopted.**

本案说明Value Realization已经走到R5以后，仍然存在一个独立问题：

> 这件权利究竟控制了什么，以及这种控制力能持续多久、是否容易绕开？

R5回答“已经实现并能够归因到哪里”。

Rights Control回答“专利权本身控制价值载体的能力有多强”。

二者不是同一层。

### H4 — Monetary evidence is contextual

**Supported by this case as a first archetype.**

2亿美元是真实、专利级、法院案件中的金额证据；同时它又不能脱离：
- 侵权主体
- 争议产品/功能
- 法律程序
- 损害赔偿方法
- 时间点

被当作专利的永久价格。

## 本轮不做什么

这一例不会触发Schema修改。

按照Issue #5预注册规则，必须等Amgen、PageRank、CRISPR等非奖项样本完成后，再判断：
- Rights Control是否值得成为正式层；
- H4是否跨交易/许可/诉讼场景成立；
- 哪些字段只是叙事信息，哪些字段真的增加解释力。

## 结构化数据

本轮同步形成：
- Source Registry
- E3 / E4 / E5 Evidence
- Patent Value Ledger
- deterministic Diagnostic / Report

下一例优先进入Amgen v. Sanofi，用“高产品价值 + 宽功能性权利要求失效”对i4i做反向压力测试。
