# 第25届样本外验证：Round 1

日期：2026-09-24  
模型：V0.6（冻结，不因本轮案例增加新预测变量）  
T0：**2024-02-05**

## 1. 为什么这一轮重要

第25届是 V0.6 冻结后的第一届样本外验证。官方通知明确，国家知识产权局接收推荐材料的截止日为 2024-02-05；因此本轮预测性分析只允许使用在该日或之前已经公开可获得的信息。

中国专利奖现行评价结构为：
- 专利质量 25%
- 技术先进性 25%
- 运用及保护措施和成效 35%
- 社会效益及发展前景 15%

本项目不尝试复刻评委分数，而是检验：冻结的公开变量能否稳定解释 Gold / Silver 差异。

## 2. Pair P25-LIFE-001：生命科学

Gold：ZL201610705624.2  
Silver：ZL202110783589.7

T0 前，Gold 对应的卡度尼利单抗已经获批上市，并进入临床指南推荐；因此从专利技术到真实临床使用的价值链已经跨过监管和临床应用门槛。

对于 Silver 的 B7H3/IL-21 CAR-iNKT 专利，本轮公开来源能够确认专利与技术内容，但没有在 T0 前建立同等级的具体上市产品或规模临床应用证据。

**结果：可观察差异存在。**  
它支持 `Real-world Validation Depth`，但不能据此声称这就是官方给出 Gold / Silver 的原因。

## 3. Pair P25-EQUIP-001：装备 / 半导体制造

Gold：ZL202010510899.7（高世代 TFT-LCD 玻璃基板生产线）  
Silver：ZL201010246628.1（CMP 设备）

这一组对 V0.6 压力很大。

Gold 侧在 2019 年已经有国内首条 8.5 代 TFT-LCD 玻璃基板生产线点火并进入产业化阶段，具有明显的国产替代和产业安全意义。

但 Silver 侧并不弱：华海清科 2021 年上交所审核材料**直接把 ZL201010246628.1**识别为“CMP 智能抛光技术中应用的重要技术”，并明确映射到核心技术；公司 CMP 设备也已进入规模化产业应用。

**结果：公开 T0 证据无法稳定区分。**

这说明：
- Centrality 不是充分条件；
- Scale 不是充分条件；
- 国产替代也不是充分条件；
- 强产业化专利仍然可能是 Silver。

## 4. Pair P25-MAT-001：先进材料

Gold：ZL201410529844.5（高强高塑 TiAl）  
Silver：ZL201811205291.2（大直径 SiC 衬底）

这是目前最有价值的“反预测”样本之一。

### Gold 侧
TiAl 专利在 T0 前已有：
- 与发明人高度重合的 Nature Materials 论文；
- 明确的强度、塑性和高温性能突破；
- 多法域专利族。

这使 `Relative Technological Differentiation` 很强。

### Silver 侧
天岳先进 2021 年招股书则直接把 **ZL201811205291.2** 映射为公司“碳化硅单晶衬底超精密加工技术”的代表性专利，并说明碳化硅衬底已经形成主营产品和规模商业化。

这使 Silver 侧的 `Patent → Core Technology → Product` 公开证据链反而更清楚。

### 结果
**公开 V0.6 不能清楚排序。**

这一对提示我们：Gold / Silver 的差异可能存在于公开互联网无法观察到的专利级经济归因、项目应用证明、专项审计，或技术先进性评价细节中。

## 5. Round 1 的结论

V0.6 暂时没有被推翻，但也没有证明可以“预测金奖”。

目前更稳健的结论：

1. `Real-world Validation Depth` 在部分生命科学样本中有解释力。
2. `Centrality + Scale + 国产替代` 不能构成 Gold 判定式。
3. Silver 可以拥有非常强的 E3（专利—核心技术映射）证据。
4. 技术突破强度与价值链证据完整度可能指向不同方向。
5. 外部公开模型存在明显 Observability Ceiling。
6. 因此本项目继续定位为 **Gold Readiness / Patent Value Benchmark**，而不是奖项结果预测器。
