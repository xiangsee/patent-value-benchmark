# 第25届样本外验证：Round 3

日期：2026-09-24  
模型：V0.6（继续冻结）  
T0：2024-02-05

本轮补齐 Milestone A 中的两个缺口：**新能源 / 电力数字化**与**软件基础设施**。  
本轮结束后，第25届 matched-pair 预览集由 5 组增至 7 组。

## P25-POWER-001：电力数字化

Gold：ZL201811455931.5  
《一种基于非向量空间控制策略的导线追踪方法及装置》

Silver：ZL202110911018.7  
《基于优先级分配的非侵入式负荷辨识电量分解方法及系统》

两者都来自电力系统组织，也都属于把算法 / 数字技术嵌入电网作业与用能管理的专利，但价值载体并不完全一致，因此不是强技术同配对。

### T0 前可以观察到的专利运用轨迹

Gold 侧：
- 具体专利的法律事件显示，2023-11-07 已有普通许可合同备案生效；
- 许可备案记录日期为 2023-10-19；
- 这可以确认“专利被实际许可运用”这一事实，但不能自动推出产品部署规模、收入或专利贡献率。

Silver 侧：
- 2022 年江苏省技术产权交易市场曾对该具体专利公开进行许可使用竞价；
- 起拍价 50 万元；
- 竞价结果标记为“流拍”。

### 判断

这组不是“Gold 有转化、Silver 没转化”。

更准确的是：

> 两边都存在 **exact-patent-level commercialization evidence**，但轨迹不同：一边有许可备案生效，一边有公开许可尝试但未成交。

因此本组只把 `Evidence Traceability` 标记为可观察差异。

不能把“成交 vs 流拍”直接解释为 Gold / Silver 的官方原因，也不能把流拍编码为专利价值为 0。

## P25-SOFT-001：软件基础设施

Gold：ZL202010520559.2  
《数据库事务处理方法、装置及服务器》（腾讯）

Silver：ZL201610658326.2  
《一种报文传输方法和装置》（新华三）

Gold 解决数据库事务与结构变更协同中的底层一致性 / 性能问题；Silver 面向 SDN + VXLAN 数据中心网络，在多租户场景中携带并执行转发优先级。

两件专利都：
- 属于企业底层软件 / 基础设施技术；
- 在 T0 前已经授权；
- 形成了海外专利族；
- 具有清楚的技术问题与权利要求结构。

但本轮在 T0 前公开资料中，没有对任一侧建立可靠的：

`Exact Patent → Named Product → Deployment Scale → Attributable Value`

2025 年腾讯获奖后的材料明确把 Gold 专利映射到 TDSQL，但这属于 T0 后的 outcome-leakage 信息，因此不能进入本轮。

### 判断

**Public T0 evidence cannot distinguish the pair.**

这意味着 Observability Ceiling 并不只发生在通信 SEP 类专利，在数据库、SDN / 云基础设施这类底层软件中同样明显。

## Round 3 新认识

### 1. “专利运用”也必须分层

许可备案、交易挂牌、产品部署、规模收入不是一回事。

可以把它们看成不同证据节点：
- 专利挂牌 / 报价：证明存在转化意图；
- 许可成交 / 备案：证明发生权利运用；
- 产品实施：证明进入价值载体；
- 规模部署：证明真实世界验证；
- 收入 / 成本 / 性能归因：才接近 E4。

不能把这些节点混成一个“已产业化”标签。

### 2. 公开可观察性具有行业结构差异

医疗器械、上市公司制造业有时可以通过招股书建立完整链条；
通信、数据库、网络基础设施则常常只能看到专利和企业级产品能力，中间的 exact-patent linkage 很难公开确认。

因此未来 benchmark 需要同时报告：
- Value Evidence
- Evidence Observability

新增案例没有提供足够理由增加预测变量。
