# China “High-Value Invention Patent” vs Economic Patent Value

## 结论

中国“高价值发明专利”统计指标非常重要，但不应被直接当作“经济价值已经被证明”的标签。

## “十四五”：五类

2021年官方规划把满足任一条件的有效发明专利计入：
1. 战略性新兴产业
2. 海外同族
3. 维持超过10年
4. 较高质押融资金额
5. 国家科技奖 / 中国专利奖

## “十五五”：当前四类说明

2026年国家知识产权局公开解读列出：
1. 战略性新兴产业
2. 海外同族
3. 维持超过10年
4. 国家科技奖 / 中国专利奖

## 为什么这件事重要

如果“高价值”是一个客观不变的经济属性，统计定义不应该随政策治理目标变化。

实际发生的变化提示：

> 这里的“高价值”同时承担创新政策、产业引导和统计治理功能。

因此Xiagsee Benchmark需要至少记录两个完全不同的字段：

- `policy_high_value_status`
- `patent_value_evidence_state`

一个回答“是否进入政策统计口径”。

另一个回答“我们实际证明了什么价值”。

两者都重要，但不能互相替代。
