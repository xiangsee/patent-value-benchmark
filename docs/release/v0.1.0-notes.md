# Xiangsee Patent Value Benchmark v0.1.0

**Release date:** 2026-10-12 (Asia/Shanghai)

First public freeze of the Patent Value Ledger / Diagnostic surface on top of the adopted V0.7 research architecture.

## Highlights

- **Schemas frozen at 1.0** for Patent Value Ledger and Patent Value Diagnostic (`schema_version: "1.0"`).
- Evidence Record and Source Registry schemas are structure-frozen with the same release (no independent version field).
- Deterministic pipeline: Ledger → Diagnostic → Markdown report, with CI drift checks.
- Cold-start path: Getting Started + `scaffold_ledger.py` + PR template; external reproduction completed (#2 / PR #22).
- Licensing: Code/CI/JSON Schema **Apache-2.0**; original docs/data **CC BY 4.0**.

## What this release is

An open, evidence-traceable framework and benchmark dataset for studying how patents become demonstrable technology assets.

Core principles remain:

1. Patent-level attribution (no automatic inheritance from enterprise/product)
2. Value construct first
3. T0 cutoff / no Outcome Leakage
4. Unknown ≠ 0
5. Screening ≠ Proof
6. Award ≠ Universal Value

If you have local draft ledgers with `"schema_version": "1.0-draft"`, change them to `"1.0"`. No other field renames are introduced by this freeze.
