# Research Tracks and Boundary Rules

日期：2026-09-24  
状态：Adopted governance rule

Xiangsee Patent Value Benchmark 从本轮起正式区分两个长期研究模块。

---

## Track A — Patent Value Benchmark

### 研究对象

研究“专利价值”本身，而不是任何奖项、政策标签或单一评分体系。

至少区分：
- Policy / Statistical Value
- Technological Quality
- Private Rights / Asset Value
- Realized Operating Value
- Social / Strategic Value

### 当前方法

V0.7继续作为正式架构：
- Value State
- Attribution / Evidence
- Observability
- Value Realization

V0.8研究：
- Rights Control
- Counterfactual Control
- Option / Future Value
- Portfolio Context
- Screening Signals

### 样本规则

通用模型后续必须逐步增加**非奖项样本**。

样本选择优先围绕待验证机制，而不是围绕“Gold / non-Gold”标签。

---

## Track B — China Patent Award Research

### 研究对象

中国专利奖制度及其结果本身。

包括：
- 金奖、银奖、优秀奖历届项目
- 评奖规则及制度变化
- 同届同领域 matched-pair
- 获奖前后的技术、产业与经济表现
- 奖项与不同 value constructs 的关系

### 模块独立性

该模块有自己的研究问题、样本设计和结论。

其结论可以是：
- “某类指标与金奖结果存在关联”
- “某种特征在历届金奖中更常出现”
- “某届制度变化改变了可比性”

但不能直接改写为：
- “该指标就是专利经济价值”
- “金奖就是高价值专利的ground truth”

---

## Cross-validation rule

两条线允许交叉验证。

### Award → General Model

某个金奖研究变量只有满足以下条件，才进入通用模型候选：
1. 有清楚的经济 / 法律 / 技术机制；
2. 在非奖项样本中仍可定义；
3. 不是奖项规则本身的同义反复；
4. 能被反证；
5. 不依赖post-outcome信息。

### General Model → Award Research

通用价值模型可以反过来用于解释：
- 为什么一些金奖项目在某些价值维度上表现突出；
- 为什么有些高现实价值专利未必获得金奖；
- 奖项究竟更接近哪一种 value construct。

但不得把结果写成奖项预测承诺。

---

## Historical provenance

第25届10组 Gold–Silver matched pairs 与第24届4组外部压力测试参与了 V0.6/V0.7 的形成。

这些历史研究继续保留，并具有双重身份：
1. 中国专利奖专项研究资产；
2. 通用架构形成过程的历史验证证据。

**保留历史，不意味着延续奖项中心主义。**

---

## Repository rule

以后新增内容默认按下列判断归档：

- 研究“专利为什么有价值” → Track A
- 研究“中国专利奖为什么这样评 / 哪些项目获奖 / 获奖项目有什么共同特征” → Track B
- 同时涉及两者 → 分别形成两个结论，并显式标注可迁移部分

不得为了方便把两个问题重新压成一个总分。
