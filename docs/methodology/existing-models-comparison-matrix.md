# 既有专利估值 / 评估族系 vs V0.7 — 一页比较矩阵（T2）

> Status: **research comparison v0**（2026-10-14 Asia/Shanghai）  
> Track: 世界级四轨路线 **T2** · [`world-class-roadmap.md`](world-class-roadmap.md)  
> Formal: **V0.7** + **schema 1.0** · **未** adopt / freeze V0.8 · **不**输出美元总分  
> 目的：说清「别人在估什么 / 我们在证什么」，不是宣称谁更准。

## 1. 读表方式

每一行是一类**常见实务或研究族系**（不是某一商业产品的认证）。列对齐世界级路线里要求的比较轴：

| 列 | 含义 |
|---|---|
| 价值建构（construct） | 谈的是哪一种「价值」 |
| 分析单元 | 专利件 / claim-set / 组合 / 产品 / 交易 |
| T0 / 信息截止 | 是否显式防 outcome leakage |
| Unknown 政策 | 缺证据时填 0、猜、还是保留未知 |
| 货币主张 | 是否直接给出金额 / 费率 |
| 与 V0.7 关系 | 互补、输入、还是易混淆替代 |

**V0.7 基准行（对照）：** 证据与实现架构 — 输出 Value / Attribution / Observability / Realization（R0–R5）；**不**输出总分；Unknown≠0；企业/产品不自动继承到件；Screening≠Proof。

## 2. 比较矩阵

| 族系 | 价值建构 | 分析单元 | T0 / 截止 | Unknown 政策（典型） | 货币主张 | vs V0.7 |
|---|---|---|---|---|---|---|
| **IVS 系无形资产估值**（市场 / 收益 / 成本；含 relief-from-royalty） | 交易或报告用的**公允价值 / 投资价值**等 | 多为**可识别无形资产**（常含专利包） | 估值日清晰；历史预测需假设 | 缺可比时改方法或加折价，少把「未知」当一等公民 | **是**（金额） | **互补下游**：V0.7 可约束「能否把收入归到该专利」；V0.7 **不是** IVS 替代品 |
| **特许费率 / 可比许可 / 利润分割** | 许可对价、避免特许权使用费 | 许可交易、技术包、有时单件 | 交易时点；外推依赖可比质量 | 无可比时常硬套行业表 | **是**（费率→金额） | 费率是 **E4/实现语境线索**，不能单凭费率抬 R；池许可 ≠ 单件价格 |
| **成本法**（重置 / 再现研发成本） | 投入重置的下限或早期参考 | 项目 / 资产 | 成本发生期 | 常忽略失败期权与市场 | 有时给出「成本额」 | 成本 **≠** 实现价值；V0.7 不把研发支出当 E3 |
| **引证 / 族 / 权利要求宽度等文献计量** | 技术影响力或「质量代理」 | 件 / 族 | 很少严格 T0；易泄漏后授引证 | 缺失常当 0 或低分 | 通常否（分数） | **Screening 层**；不得短路为 R3+ 或价值事实 |
| **ML / 商业「专利打分」产品** | 多为黑盒「价值分 / 等级」 | 件或组合 | 训练窗常不透明 | 模型填补 → 假精确 | 有时映射美元 | **高混淆风险**；V0.7 要求可复核证据链，拒绝无归因分数 |
| **奖项 / 高价值认定 / 政策标签**（含中国专利奖等） | 评审或政策口径的荣誉 / 统计标签 | 项目或件 | 评奖日；事后叙事多 | 未获奖 ≠ 无价值 | 通常否 | **Track B 独立**；可作外部信号，**不是**通用目标变量 |
| **诉讼损害赔偿 / 合理许可费裁判** | 侵权救济语境下的经济补偿 | claim / 产品 / 期间 | 裁判与事实审截止较清 | 未决 → 不计入终局 | **是**（判赔 / 费率） | 强 **E4 / Rights 语境**；R5 ≠ 权利控制本身（见 RC 研究） |
| **期权 / 实物期权叙事**（早期技术） | 未来选择权 | 件或项目 | 早期 T0 关键 | 常过度讲故事 | 模型可出金额 | 与 Package B「早 T0 停 R0」一致：**期权叙事 ≠ 已实现价值** |

## 3. V0.7 明确拒绝与既有族系对齐的说法

1. 「引证高 / 打分高 ⇒ 高价值专利」  
2. 「得奖 / 入选高价值库 ⇒ 通用经济价值」  
3. 「有行业特许费率表 ⇒ 可直接给该件定价」  
4. 「产品热销 ⇒ 某件专利已到 R3+」（缺 exact carrier 映射则 Unknown）  
5. 「判赔金额 = 专利资产市值」  
6. 「Unknown 可以当 0 以便打总分」

## 4. 我们仍可向既有族系**学习**什么

| 从… | 学什么（不照搬目标） |
|---|---|
| IVS / WIPO 技术转移估值指南 | 先定价值基础与前提；方法要与数据匹配 |
| 特许 / 可比交易 | 记录许可结构、地域、排他、包内分摊 — 供日后 E4 |
| 引证 / 族 | 作冷启动**召回**与筛选，不作证明 |
| 诉讼材料 | claim-set 终局、救济类型、分摊论证 — 喂 RC / RP 研究 |
| 期权思维 | 早 T0 诚实停在 R0/R1，保留未来选择权字段 |

## 5. 一句话定位

> **既有估值族系多在回答：「值多少钱？」**  
> **V0.7 先回答：「在何种建构与 T0 下，有哪些可复核证据表明价值已实现到哪一步——以及何处仍是 Unknown。」**

金额与费率可以成为**后续层**（需显式建构 + E4），不是 V0.7 的正式输出。

## 6. 非目标 / 版本边界

- **不** adopt V0.8；**不**改 schema 1.0；**不**编码新 ledger。
