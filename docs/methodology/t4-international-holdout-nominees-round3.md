## Purpose

Round 1/2 已覆盖 US / EP（部分）/ JP / KR。本轮专攻 **EP(UK) 效力 + 英国法院 / UK SPC** 轨道，仍按三类混搭：

| 桶 | 目标 | 期望压力 |
|---|---|---|
| **(a) R0 discipline** | 英/欧消费或专业设备品牌叙事强，缺 exact-patent↔SKU | 停 R0；拒假抬 |
| **(b) Checkable E3** | UK SPC 或 MA+SmPC 可对制剂/化合物 claim | 诚实 R3（仍无 E4）；允许 FAIL |
| **(c) Possible E4** | 英国法院**点名单件 EP(UK)** + 损害金额 | 有 E3+exact_patent 指标才可谈 R5；判赔≠自动 R5 / ≠ FMV |

- Dyson / Numatic：刻意选**产品环境强、专利号不钉 SKU** 的英系设备。

- **INT-15**：UK SPC 显式 basic patent ≈ US OB / KR Green List 形态。  
- **INT-16**：有药无有效 SPC → 允许诚实 FAIL；**禁止**用 Xadago 品牌叙事抬 R3。  
- **未**再提名 INT-4 Aubagio EP 同族。

### (c) E4
- **INT-17** 优先作主 E4（£13.4M 单件清晰）。  
- **INT-18** 教 territoriality / 和解头 vs 诉请头。  
- **未**再提名 INT-6 BGH EP-1070223。
