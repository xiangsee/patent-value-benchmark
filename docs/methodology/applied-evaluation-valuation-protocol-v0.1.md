# 应用型专利评价与货币估值：双轨准入协议 v0.1

> 日期：2026-10-29
> 状态：**research-only applied protocol；不是正式 V0.8，不修改正式 Ledger / Diagnostic schema 1.0**
> 来源：真实初审表与专利清单的内部复盘，**本公开文件不上传用户提供的参赛记录、企业转化材料、历史单项分数或权属信息**。
> 相邻研究：`model-v0.7.md`、`t2-scenario-selection-decision-tree.md`、`t4-inter-rater-blind-protocol-h-e3.md`

## 0. 一句话修改

**专利评价、货币估值、证据充分性是三个不同的输出对象。**

- **评价（Assessment）：** 为特定目的比较技术质量、权利质量、运用与影响；可产生场景内专家分数，但不等于资产价格。
- **估值（Valuation）：** 在明确价值基础、估值主体、权利对象、时点、现金流或市场数据时估计货币价值；没有必要数据不估价。
- **证据诊断（Evidence Diagnostic）：** 说明每条主张的scope、E1–E5、T0、观测性、反证和需要补充的材料。

评价指标与估值方法**必须平行显示**，禁止`评奖高分 × 固定系数 = 货币价值`。

## 1. 应用场景优先声明

一次评估至少声明：

| 输入 | 需要记录的内容 |
|---|---|
| decision_question | 评奖初审 / 专利布局 / 许可谈判 / 交易 / 质押 / 企业内部投资 |
| value_construct | policy/quality/asset/realized/strategic；不得混用 |
| rights_subject | exact patent、claim set、portfolio、许可权或未来应收款 |
| ownership_and_jurisdiction | 当前权利人、共同权人、司法辖区和权利期限 |
| as_of_date | 冻结T0；历史评分仅为过去时点事实 |
| basis_of_value | 市场价值、特定主体投资价值、许可谈判/争议语境等；未定义则不得给金额 |
| data_boundary | 公开/受监管披露/内部/受限；个人或客户资料不得进入公共库 |

## 2. 评奖 / 初审 sidecar（不改变V0.7不打分原则）

在明确采用**中国专利奖发明/实用新型**评价构念时，可以采用官方四项权重：

- 专利质量 25%：新颖性、创造性、实用性、文本；
- 技术先进性 25%：原创性/重要性、同类技术对照、通用性；
- 运用及保护措施和成效 35%：具体运用、保护、经济效益、市场份额；
- 社会效益及发展前景 15%：社会效益、行业影响、政策适应。

官方出处：[国家知识产权局《评奖办法（2023年修订）》](https://www.cnipa.gov.cn/art/2024/2/1/art_394_190100.html)。

**这不是V0.7新增的“Patent Value Score”。** 它是 Track B 在特定评奖场景下的专家评价工作表，与通用Patent Value Diagnostic分离。

### 专家分数输出门槛

- 仅有专利摘要/引用/主权项长度：**可给技术线索和问题清单，不应强制给正式分项分数**。
- 已有claim/prior-art对照但缺实施证明：可形成技术/专利质量初评；运用成效列`待核`，不把Unknown记0。
- 四维都经逐项证据和专家复核：才显示加权综合分；证据状态与结果并排。
- 缺项时可保留**无分数的条件性意见**，不得用其他维度填补缺口、不得用历史分数冒充新专家结论。
- 涉及资格/权属问题：另开Hard Gate；不是靠得分抵消。

公式只在输入获得证据支撑后启用：
`AwardScore = .25 Quality + .25 Technical + .35 UseProtection + .15 Social`。

## 3. 历史评分校准的正确方法

历史初审结果是**历史场景下的判断**，不是专利真实货币价值，也不是未观测的金奖标签。必须分别检查：

1. **量纲：** 旧“经济价值/估值”字段有无币种、单位、估值日、基础、方法；任一缺失不得转成货币金额。
2. **分数离散度：** 分档、并列、同分排序和各种子项的原始量尺（可能超过100）先做审计；不得直接当0–100标准化评分。
3. **样本选择：** 若提交的回顾样本集中在历史高分群体，无法证明模型适用于普通专利或无实施专利。
4. **信息污染：** 新评分者若已经看过历史分数或产业化结果，相关性只作描述，不能声称盲测预测效度。
5. **时点泄漏：** 对历史T0的评价，只能使用当时可得证据；今后销售/药品获批/专利转让不能回填T0。

真正的验证应采用：预注册规则、未参与建模的样本、盲法双评委、两轮协调与留存的分歧、按技术领域分层的error/coverage报告。关注拒绝假归因的能力，而不只是分数相关性。

## 4. 货币估值准入（五道硬闸）

以下为**完整货币估值报告的准入要求**，不是让全部专利自动通过的评分卡。

| Gate | 必须问 | 未通过时 |
|---|---|---|
| G0 Rights & Purpose | 估值目的、价值基础、具体权利对象、权属、负担、期限是否明确？ | 不输出金额；补登记/合同/价值基础 |
| G1 Technical & Legal | 权利要求、相关替代技术、有效性/可执行状态是否足够清楚？ | 法律与技术尽调，不从行业得分推值 |
| G2 Attribution | 是否有本件权利到产品/工艺的 E3 映射，**或合同准确列明被估权利**？ | 停止从产品或企业收入继承到单件 |
| G3 Economics | 是否有同scope可核的净现金流、节约成本、真实可比交易或合同分成？ | 仅作场景/假设；不得填货币结果 |
| G4 Horizon & Risk | 剩余经济寿命、辖区、税、折现、依赖资产、续费及风险是否有据？ | 不给“确定市值”，先补假设和敏感性 |

金额输出级别：

- **L0—Not Valuation Ready：** 未具备合法对象或可归因收益，报告只给诊断与补证。
- **L1—Scenario Only：** 明确是假设模型；可做参数敏感性分析，不称实测资产估值。
- **L2—Indicative Range：** G0–G4材料足够，低/中/高情景及方法交叉核验，可作研究性区间；每个金额带scope与T0。
- **L3—Formal Appraisal Handoff：** 质押、出资、财报、涉税、监管等要求正式估值时交有资格的机构，研究结果仅供底稿。

**缺数不能填0，也不能填行业典型平均值来冒充项目事实。**

## 5. 估值路径应按经济对象选择

| 情形 | 可以优先研究的方法 | 最重要的归因要求 |
|---|---|---|
| 单件专利明确写入许可合同，合同有实际收款 | 许可净现金流 / 权利交易比较 | 合同权利清单、支付与受益方分配、许可地域和期限 |
| 生产工艺降低能耗、缺陷率、制造成本 | With-and-without / Incremental cash flow | 有无该技术的真实同类工艺对照，排除其他设备/诀窍贡献 |
| 有可比的独立专利许可/交易 | Market approach | scope、地域、行业、期限、排他性、对价结构调整 |
| 有可信的产品收入基数及可辩护许可费率 | Relief-from-royalty | 明确“本专利覆盖份额”；若费率已是单件费率不得再次分摊 |
| 研发早期尚无现金流，但有可替代开发路径 | Replacement-cost/option sensitivity辅助 | 成本不是市值；不因未来成功反填早期R-stage |
| SEP、组合许可、判赔、质押贷款额 | 各自的合同/FRAND/损害/金融构念 | **不**把池费率、组合交易额、判赔额或贷款额认作单件价格 |

一般现金流基线（**只在净收益已归因到指定权利后**）：

`IndicativeValue(T0) = Σ_t [NetCashFlow_attributable(t) / (1+r)^t]`

- 所有现金流必须记录所归属的专利/组合/合同权利；
- 合同已有现金收付 ≠ 同额市场价值；
- 未来收益应按法律/经济剩余寿命截止；
- 折现率/概率应有市场和风险依据，不用“专利评分”代替；
- 许可费 + 同一未来应收款出售对价不能当作两份独立收益相加；
- 若采用成本法、市场法、收益法的不同结果，应该解释差异而不是直接平均。

外部方法参照：[WIPO IP Valuation](https://www.wipo.int/en/web/business/ip-valuation)；[WIPO 2025技术转移估值指南](https://www.wipo.int/web-publications/intellectual-property-valuation-basics-for-technology-transfer-professionals/en/3-ip-valuation-methods.html)。

## 6. 报告输出合同（建议）

一份实战报告应给出四个并列表面：

1. **Evaluation View：** 场景标准、关键技术判断、专家分项分数（若材料足够）、负面证据；
2. **V0.7 Evidence View：** E1–E5、R0–R5、T0、确切权项映射、Unknown及下一证据任务；
3. **Rights / Realization View：** 可选使用RC/RP实验对象，标注非正式性，避免金额继承；
4. **Valuation View：** 价值基础、估值对象、准入状态、选用方法、场景区间或明确“暂不出金额”。

质量保证单独跟踪：数据来源、证据冲突、盲评一致性、权属更新、异议/纠错及版本变更。

## 7. 反方测试清单

在报告签发前必须逐项询问：

- 如果把权利人企业名称遮住，技术质量判断会否大幅下降？
- 没有真实权项映射，是否仍给出高`运用成效`分或专利级收益？
- 旧评委分数是否泄漏到当前初评分项？
- 历史企业收入、药品销售、工程回款、质押金额是否误继承到专利？
- 有许可发生，就等于许可费实际已收吗？
- 有诉讼判赔，是否误认已收现金？
- 有完整事件记录，但缺现金流，是不是仍输出“亿元估值”？
- 对`Unknown`是否默默按0扣分？
- 专利被证明无法使用、权利范围变窄或经济寿命缩短后，估值场景是否重新计算？
- 单一价值结论能否追溯所有关键数据、权利对象、时点和反方证据？

真实评奖原表、商业材料、客户文件及逐件评分留在受控工作底表，**不公开上传至本仓库**。
