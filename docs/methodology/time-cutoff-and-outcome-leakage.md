# T0 Cutoff & Outcome Leakage Protocol

## 为什么需要 T0

如果研究者在知道最终奖项以后，再使用获奖后的企业宣传、媒体报道或复盘材料解释“为什么它会获奖”，模型可能只是学到了结果本身。

这称为 **Outcome Leakage（结果泄漏）**。

## T0 定义

对于每一届中国专利奖：

> **T0 = 国家知识产权局接收该届推荐材料的官方截止日期**

历史复原和样本外验证原则上仅使用 T0 当日或之前已经存在的证据。

例如：
- 第 26 届：以该届官方推荐材料截止时间为 T0
- 第 25 届：T0 = 2024-02-05

## 不应进入预测变量的信息

- T0 之后的获奖宣传
- 获奖后企业对该专利价值的专项总结
- 以“获得金奖”为前提形成的新闻材料
- 后续市场表现，除非研究目标明确是事后评价

## 可以使用的信息

只要在 T0 前已经形成并可验证，例如：
- 专利与专利族数据
- 上市产品资料
- 年报 / 招股书
- 临床与监管批准
- 国家 / 行业标准
- 工程应用
- 产品销量与市场份额
- 许可、备案、审计等

每项证据至少应记录：
- source
- source_date
- observed_at / cutoff
- evidence_level
- inference_status
