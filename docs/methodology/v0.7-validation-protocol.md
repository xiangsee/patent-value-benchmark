# V0.7 External Validation Protocol

状态：适用于 V0.7 Proposal 的外部验证；不代表 V0.7 已正式 adopted。

## 验证集

第24届中国专利奖。

T0：**2022-10-31**

依据：国家知识产权局关于第二十四届中国专利奖的通知中规定，全国报送材料截止日期为2022-10-31。

## 冻结与防泄漏

1. 第25届数据与结论冻结。
2. 第24届 award label 仅作 outcome label。
3. T0 之后的来源可以：
   - 确认最终奖项；
   - 进行 post-T0 ground-truth check。
4. T0 之后的来源不得：
   - 回填 T0 evidence；
   - 提高 T0 attribution；
   - 提高 T0 realization stage；
   - 被用于解释“为什么获奖”。

## 四层同时记录

### 1. Value State
现实技术 / 产品 / 工程 / 临床价值处于什么状态。

### 2. Attribution / Evidence State
证据是否能把这些价值归因到 exact patent。

### 3. Observability State
证据在T0时：
- Public
- Disclosed / Regulated
- Internal
- Restricted
- Unknown

中的哪一种。

### 4. Value Realization Stage
- R0 Right Exists
- R1 Market / Transfer Intent
- R2 Rights Transaction
- R3 Implemented in Value Carrier
- R4 Scaled Real-world Validation
- R5 Patent-level Attributable Value

## 重要限制

Public validation 只能判定“公开可观察状态”。

当 exact-patent linkage 不公开时，即便后来知道产品已经大规模商业化，也不得在 T0 数据中偷偷把产品价值继承给该专利。

## Adoption rule

V0.7 至少完成第24届4–6组跨行业 matched-pair 后，才讨论是否 adopted。

如果新架构不能稳定减少以下混淆，则不升级：
- low value vs unobservable value
- product value vs patent value
- commercialization intent vs implementation
- implementation vs scaled validation
- scaled validation vs patent-level attribution
