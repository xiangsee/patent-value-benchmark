# Evidence Levels

本项目区分“价值是否存在”和“外部研究者是否能够观察到该价值”。

## E1 — 企业级证据

示例：
- 企业收入与研发投入
- 企业行业地位
- 企业专利总量
- 企业整体许可与市场表现

用途：描述创新环境。

限制：**不得自动向下归因给具体专利。**

## E2 — 产品 / 项目级证据

示例：
- 产品销量、销售额、市场份额
- 工程项目数量
- 临床 / 患者使用
- 平台设备量或用户量

用途：证明价值载体具有现实价值。

限制：产品价值仍不能自动等同于其中每一件专利的价值。

## E3 — 专利—价值载体映射证据

证明具体专利进入具体：
- 产品
- 模块
- 工艺
- 平台
- 工程
- 药物 / 医疗器械

这是从“好产品”走向“高价值专利”的关键连接层。

## E4 — 专利级价值归因证据

示例：
- 因该技术性能提升 X%
- 成本下降 Y%
- 良率 / 产能提升
- 增量收入 / 利润
- 许可价值
- 具体项目与订单贡献

这是目前公开数据中最难获取、但最有解释力的证据层。

## E5 — 独立核验证据

示例：
- 专项审计
- 监管批准
- 标准文件
- 合同 / 许可备案
- 客户应用证明
- 第三方测试

## 判断状态

每一个字段应同时保留证据状态：

- **Confirmed**
- **Strong Evidence**
- **Inference**
- **Unknown**

硬性规则：**Unknown ≠ 0**。
